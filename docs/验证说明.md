# 初始版本验证说明

## 运行方式

在仓库根目录执行：

```powershell
npm.cmd --prefix tools run pack
npm.cmd --prefix tools run check
```

核心检查脚本只使用 Node.js 内置模块，不需要安装 Mermaid 或 Playwright。重新生成硬件图形、三维场景检查和 Groq 3 浏览器检查需要先安装 `tools` 中锁定的开发依赖。Linux / macOS 将命令中的 `npm.cmd` 替换为 `npm`。

单独核对资料引用可执行 `npm.cmd --prefix tools run check:references`。该检查同时核对源码、独立 HTML 和说明文档，要求外部资料使用公开 HTTP(S) 链接，并检查仓库内部文档导航是否存在。

## 报告与仓库约定

七类功能检查将中文 UTF-8 报告写入 `reports/`：性能计算、多芯片通信、算子与硬件、动画播放、界面与镜头、逐周期执行、完整请求流程。引用检查直接在控制台输出结果。

`reports/` 已加入忽略规则，不提交自动生成的检查记录。报告采用功能名称，检查过程不会重新在仓库根目录生成“第几版”文档。仓库长期维护 `README.md` 和 `docs/` 中的解析方案、设计说明、验证说明三份文档。

提交前应重新打包并运行全部检查，确认独立 HTML 与 32 个源脚本、9 份样式一致，并检查待提交内容中没有依赖目录、临时报告或旧版网页。

## 初始版本验证范围

当前包含默认 WebGL 空间以及保留的兼容视图运行代码、Mermaid 图形和参数化计算模型。发布检查以当前源文件及重新生成的独立 HTML 为对象，检查报告统一输出到忽略目录。

核心 76 组检查不包含交互网页的浏览器点击、截图或视觉验收，也未连接真实 Groq 硬件。逐周期验证支持示例模型内部的整数时序一致性；参数化性能结果不属于设备实测。

资料链接的形式检查不请求网络。公开原文的访问记录及出版站点的验证限制见仓库说明中的公开资料表；不把网络状态当作动画功能测试结果。

## 三维场景检查（可选）

安装 `tools` 中锁定的开发依赖后，执行 `npm.cmd --prefix tools run check:spatial`。该命令用 Playwright 渲染独立的 Mermaid 硬件场景；Windows 默认寻找 Microsoft Edge，也可通过 `SPATIAL_BROWSER` 指定浏览器路径。它不加载产品网页，不属于完整网页的浏览器点击验收。

六组检查覆盖硬件标签与几何保持不变、每片一个 VXM、两类悬浮层同时显示、高度与俯视切换、双层同钟动画及回拖、C2C 路线与镜头同步、窄画布卡片可见性。结果写入 `reports/三维分层场景验证.md`，独立场景截图写入忽略目录 `预览/`。核心 76 组检查仍只依赖 Node.js 内置模块。

## 旧版 Groq 3 / LPX 假设视图检查

安装开发依赖后执行 `npm.cmd --prefix tools run check:groq3`。命令依次运行 9 组模型检查和 15 组浏览器检查；后者使用 Playwright 和 Microsoft Edge，亦可通过 `SPATIAL_BROWSER` 指定可用浏览器。

模型检查覆盖 32 × 8 的硬件数量、64 层 FFN 的 TP2 映射无重叠、UTF-8 Prompt 与情景 Token 字节、BF16 输入与 FP32 部分和、权重流量与当前输出量的区别，以及 BF16 不借用 FP8 峰值。Flash-Next 另外核对参数组成、48 层全部 512 个专家的放置、EP8 / EP16 单片容量、跨托盘与跨机架编号、所选专家成本、路由矩阵与同片无 C2C 情况。

浏览器检查实际打开独立 HTML，验证五层硬件导航、27B 十五步与 Flash-Next 十六步主线、32 个槽位与八颗芯片选择、旋转时两侧菜单完全固定、备用槽位不会显示当前请求执行、层数与芯片映射、实时数字、参数合法性、图层、托盘展开、连续播放 / 暂停 / 重播 / 结束，以及切换原有视图时暂停。MoE 还验证第 48 层 E507 的跨托盘路线与根片切换，以及同片 / 远端专家回传量。1280 × 800 与 760 × 780 下检查单屏和双侧固定布局。断网时内嵌硬件与动画仍可使用；纹理请求仅允许来自官方芯片图 URL。

两类报告分别写入 `reports/LPX模型验证.md` 和 `reports/Groq3空间验证.md`；五层截图写入忽略目录 `预览/`。它们验证界面、情景计算与状态，不执行真实 Qwen 推理，也不代表芯片实机或制造尺寸验证。

## 当前默认空间验证

执行 npm.cmd --prefix tools run check:immersive。13 组来源与数值检查依据固定官方配置、参考实现与 Tokenizer 快照，覆盖全部层类型、状态形状、27B 门控差异、MoE 重归一化、QSA、完整 FFN 容量与数据口径。还检查首 Token 的位置、每层往返依赖、Embedding 只在每轮执行一次、未知信息不伪装成实测。

浏览器检查实际打开独立 HTML，覆盖三维实体、固定菜单、Token 驻留、拆解与导航、逐层前进、CX-9 / Spectrum-X 路线、来源差异提示、Mermaid 协作图、单屏及离线启动。具体通过数量由本次报告输出，不沿用旧版通过数字。

检查没有执行模型权重，没有连接 Groq 3 芯片，不能验证真实激活、专家编号、机器指令或 latency。页面时间轴是视觉回放进度。基础兼容视图检查继续保留，其示例参数不作为实际 Qwen / LPX 部署证据。

语义事件版本另外执行 npm.cmd --prefix tools run check:semantic：10 组数值与状态检查，20 组实际浏览器检查。覆盖逐 Token 追加、UTF-8 范围、数学参考值、ACC 读写顺序、KV 追加、背压、完整性提交、回退、自动播放、未知 owner，以及 1280 / 1600 的完整矩阵和控件可见性。新增覆盖旋转隔离、窗口按钮与滚轮缩放、两块区域的顺序、Mermaid 流程点击与算子联动。旧交接检查入口 check-contract-browser.cjs 转入同一组语义浏览器检查。

单步事件是数学与数据依赖的展开，不是硬件周期。状态快照未模拟流水深度、bank 冲突、舍入或真实网络协议，检查不能证明实机性能。
